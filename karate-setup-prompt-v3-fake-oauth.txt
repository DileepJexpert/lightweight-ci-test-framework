  The fake endpoints always say "valid". The request reaches the controller.

    - @EnableOAuth annotation behaves exactly as in production

STEP 4 — CREATE FakeOAuthServer.java (the heart of the bypass)
────────────────────────────────────────────────────────────────────────────────
Create src/test/java/com/example/test/FakeOAuthServer.java
(use your project's base package — match the package of your main controllers):

  package com.example.test;   // ADJUST to your project's package

  import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
  import org.springframework.context.annotation.Profile;
  import org.springframework.web.bind.annotation.*;
  import java.util.Map;

  /**
   * In-process fake OAuth server.
   *
   * Replaces the real Ory Hydra / STS / Decryption / EA endpoints during Karate tests.
   * The internal @EnableOAuth library still runs its full validation flow — it just
   * happens to be calling these endpoints (in the same JVM) instead of real services.
   *
   * Active only when:
   *   - Spring profile 'test' is active
   *   - Property oauth.fake-server.enabled=true
   *
   * Production is unaffected because both conditions must be true to load this bean.
   */
  @RestController
  @Profile("test")
  @ConditionalOnProperty(name = "oauth.fake-server.enabled", havingValue = "true")
  public class FakeOAuthServer {

      /** Mocks Ory Hydra's RFC 7662 token introspection endpoint. */
      @PostMapping({"/fake-oauth/oauth2/introspect", "/fake-oauth/introspect"})
      public Map<String, Object> introspect(@RequestParam(value = "token", required = false) String token) {
          return Map.of(
              "active",    true,
              "scope",     "dev-portal-suite openid offline",
              "client_id", "karate-test-client",
              "username",  "karate-test-user",
              "sub",       "karate-test-user",
              "token_type","Bearer",
              "exp",       System.currentTimeMillis() / 1000 + 3600,
              "iat",       System.currentTimeMillis() / 1000,
              "iss",       "http://localhost/fake-oauth"
          );
      }

      /** Mocks the STS token endpoint (client_credentials grant). */
      @PostMapping({"/fake-oauth/oauth2/token", "/fake-oauth/token"})
      public Map<String, Object> token() {
          return Map.of(
              "access_token", "fake-karate-test-token",
              "token_type",   "Bearer",
              "expires_in",   3600,
              "scope",        "dev-portal-suite"
          );
      }

      /** Mocks the Hydra Decryption Service — returns the token as-is. */
      @PostMapping({"/fake-oauth/decrypt", "/fake-oauth/decryption/decrypt"})
      public Map<String, Object> decrypt(@RequestBody(required = false) Map<String, Object> body) {
          String token = body != null && body.get("token") != null
                  ? body.get("token").toString()
                  : "fake-karate-test-token";
          return Map.of(
              "decrypted_token", token,
              "scope",           "dev-portal-suite",
              "client_id",       "karate-test-client"
          );
      }

      /** Mocks the EA server validation endpoint. */
      @PostMapping({"/fake-oauth/ea/validate", "/fake-oauth/validate"})
      public Map<String, Object> eaValidate() {
          return Map.of(
              "valid",     true,
              "scope",     "dev-portal-suite",
              "client_id", "karate-test-client"
          );
      }

      /** Mocks Hydra's well-known JWKS endpoint (in case library fetches public keys). */
      @GetMapping({"/fake-oauth/.well-known/jwks.json", "/fake-oauth/jwks"})
      public Map<String, Object> jwks() {
          return Map.of("keys", java.util.List.of());
      }
  }

  IMPORTANT: After examining the internal library, you may discover it calls additional

  function fn() {
    var env     = karate.env || 'test';
    var baseUrl = karate.properties['service.base-url']
                  || java.lang.System.getenv('SERVICE_BASE_URL')
                  || 'http://localhost:8080';

    // In test mode the fake OAuth server accepts ANY non-empty Bearer token.
    // In QA/SIT/Prod pass a real STS-issued token via -Dauth.token or AUTH_TOKEN.

                    || java.lang.System.getenv('AUTH_TOKEN')
                    || 'karate-test-token';

    karate.configure('readTimeout',    15000);
    karate.configure('retry', { count: 10, interval: 250 });
    karate.configure('logPrettyRequest',  true);
    karate.configure('logPrettyResponse', true);

    karate.configure('headers', function() {
      return {
        'x-request-id':  'auto-' + java.util.UUID.randomUUID(),
        'Authorization': 'Bearer ' + authToken
      };
    });

    return {
      env:       env,
      baseUrl:   baseUrl,
      authToken: authToken,
      defaultHeaders: {
        'Content-Type':     'application/json',
        'x-correlation-id': 'test-' + java.util.UUID.randomUUID()
      }
    };
  }

────────────────────────────────────────────────────────────────────────────────
We do not bypass @EnableOAuth and we do not modify the internal OAuth library.

required scope. Production is unaffected: the fake controller is loaded only
when both spring.profiles.active=test AND oauth.fake-server.enabled=true.
